# VehicleCare Tracker

VehicleCare Tracker is a desktop application developed in Python to help users manage and monitor vehicle maintenance records. The system allows users to register vehicles, record maintenance services, update mileage, track maintenance costs, view service history, and receive maintenance reminders through a modern and user-friendly interface.

## Features

* User Registration and Login
* Vehicle Management
* Mileage Tracking
* Maintenance Service Recording
* Service History
* Maintenance Cost Reports
* Service Reminders
* Dashboard Statistics and Analytics
* AI Maintenance Assistant (Prototype)

## Technologies Used

* Python
* CustomTkinter
* JSON

## Installation

### Run from Source

1. Clone the repository:

git clone https://github.com/alexandrebayanza-maker/VehicleCare.git

2. Install the required library:

pip install customtkinter

3. Run the application:

python main.py

### Run the Executable

If a compiled executable (.exe) is available in the Releases section, simply download it and run it on Windows.

## Important Note

VehicleCare Tracker is a Windows desktop application built with CustomTkinter.

The application cannot be opened directly from a phone or web browser. Mobile users can watch the YouTube demonstration video to see the application's features and functionality.

This project was developed to provide a simple and practical solution for managing vehicle maintenance records while improving skills in Python programming, GUI development, data management, and software design.
